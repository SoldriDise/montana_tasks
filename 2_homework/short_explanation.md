# Что произойдёт, если на Шаге 2 ты ошибочно используешь `usermod -G developers frodo` (без `-a`) для пользователя, у которого УЖЕ есть группы `sudo` и `adm`?
Пользователь, будет добавлен в группу developers, при этом он будет удалён из всех доп. групп: `sudo`, `adm` и т.д. Из-за этого пользователь теряет привилегии админа, т.к. он вылетит из групп: `sudo`  и `adm`. Команда `usermod -G` перезаписывает список групп у пользователя
